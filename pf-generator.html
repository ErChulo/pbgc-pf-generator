    Welcome

    This app writes the PF — the plan factors workbook — from plan documents. It does not read the documents itself.

    How it works, in 5 steps: download the scraper prompt · feed the prompt and the documents to an LLM · upload the JSON the LLM returns · review each factor set · generate the Excel workbook.

    The LLM proposes. The app checks. You decide. Nothing leaves this page — there is no server.

    Help

    What is a PF?

    One Excel workbook. One tab per set of factors the plan uses: early retirement factors, late retirement factors, benefit form conversion factors, and any other factors for benefits. Each tab is set to print.

    What does the LLM do?

    It reads the plan documents and finds every distinct factor set — each era, each type, each form pair — with the rule, the numbers, and a citation. It returns JSON. It never writes the workbook.

    What does the app write in the cells?

    Formulas, not values — except values the document table prints, which are copied as printed. Plain Excel formulas where the rule is arithmetic. BCV add-in formulas (ERFAEQ, LRFAEQ, BFCFAEQ) where the rule is actuarial equivalence, with every argument from the plan documents. They compute in Excel with the ATPBGC add-in. All factors round to 4 decimals.

    What does PBGC honor?

    PBGC honors only conversions from the normal single form to the normal married form. A conversion the prior administrator used that is not that pair is left out of the workbook. The review screen names it and says why.

    What if the scraper missed a conversion?

    Add it yourself in Review, under Additional conversions. Pick any from-form and to-form, fill in the BCV arguments, and it gets its own tab. If PBGC does not honor that pair, tick “Include it anyway” — that is the override, and the audit log records it.

    Can I fix a value without editing the JSON?

    Yes. In Review, click Edit on a set and change any field: interest, mortality, method, sexes, ranges, dates, citation. Save checks every value first. A saved edit clears the set’s decision, so approve it again. Each row also shows the exact formula that will be written, so you can check it before you generate.

    What if a factor set is missing?

    Reject it in review and it stays out of the workbook. The workbook holds only sets you approved.
